# Project 01: Invoice Data Entry

## Project Overview

This is a self-initiated portfolio project demonstrating the process of transcribing information from invoice images into a structured spreadsheet.

## Objectives

- Convert information from invoice images into digital records.
- Organize invoice details into consistent spreadsheet columns.
- Verify entered information against the original source images.
- Document data quality checks.

## Tools

- Microsoft Excel or Google Sheets
- GitHub for project documentation

## Workflow

1. Collect suitable invoice sample images.
2. Review the source documents.
3. Transcribe the information into a spreadsheet.
4. Validate the entries against the original images.
5. Prepare the final spreadsheet and quality check summary.

## Deliverables

- Source image samples, subject to usage permissions
- Structured spreadsheet
- Data validation summary
